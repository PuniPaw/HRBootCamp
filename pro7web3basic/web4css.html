CSS를 적용하는 방법 : CSS 스타일을 적용할 때에는 세 가지 방법을 사용할 수 있다.
- 인라인 스타일(Inline style)
- 내부 스타일 시트(Internal style)
- 외부 스타일 시트(External style)  CSS 파일을 따로 작성하고,  그 파일을 link 하여 사용.
선택자(selector)
- 선택자란 CSS로 UI 의 어느 부분을 디자인할지, 즉 표현할 대상이 되는 부분을 말한다.
- 선택자의 종류는 type선택자, id선택자, class선택자, 전체선택자, 하위선택자, 자식선택자...
